# Baccarat Counter – v21.2.123 Testbuild

[Windows-Testbuild herunterladen](https://github.com/benkahnt/baccarat-counter/raw/refs/heads/main/BaccaratCounter_v21_2_123_TESTBUILD.zip)

ZIP vollständig entpacken und `build/BaccaratCounterV123.exe` starten.
Das Paket enthält die Windows-Anwendung, den Quellcode und die lokalen Tests.

**Entwicklungsstand:** Testbuild, keine abschließend live geprüfte Freigabe.
Die zuverlässige Sitzungserhaltung ist nicht bestätigt. Keine automatische
29-Minuten-Wette enthalten. Der Test-Button kann echte Einsätze auslösen.

Nativer Windows-Build, 44 Regressionstestgruppen und 26 isolierte
Evolution-Browserfälle geprüft. Isolierte Tests belegen keine vollständige
reale Wettabwicklung. Hinweise und Dateiprüfsummen stehen zusätzlich im ZIP.
